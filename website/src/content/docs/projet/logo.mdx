Le logo a été choisi par l'équipe (issue #4, proposition « Monogramme circuit »). Il reprend
les symboles de l'éditeur de schéma :

- un grand **P** dont la patte se termine par une **borne de circuit** bleue : un point de
  connexion plein et une borne ouverte ;
- le point du **i**, dessiné comme une **broche non connectée** de l'éditeur : un cercle rouge
  avec un intérieur rouge très clair.

Le grand **P** est la première lettre du nom : il est collé à « sice », pour qu'on lise
directement **Psice**.

## Couleurs

| Couleur | Code | Où |
|---|---|---|
| <span style="color:#0F172A">■</span> Bleu nuit | `#0F172A` | Lettre P et texte « sice » |
| <span style="color:#2563EB">■</span> Bleu | `#2563EB` | Point de connexion et borne ; couleur principale de ce site |
| <span style="color:#DC2626">■</span> Rouge | `#DC2626` | Contour du point du « i » |
| <span style="color:#FADEDE">■</span> Rouge très clair | `#FADEDE` | Intérieur du point du « i » |
| Blanc | `#FFFFFF` | Fond |

En mode sombre, ce site affiche une variante où le bleu nuit est remplacé par un blanc cassé
(`#F1F5F9`), pour que les lettres restent lisibles.

## Animation

Pour la démonstration et l'écran de démarrage, une animation d'environ une seconde et demie :
la borne apparaît, une étincelle trace le grand P, le point de connexion s'allume, les lettres
de « sice » montent l'une après l'autre comme une vague, puis le point du « i » lance une onde
rouge, comme une alerte.
