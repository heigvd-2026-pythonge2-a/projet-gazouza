Psice est livré comme une **application Windows portable** : un dossier zippé qui contient tout ce
qu'il faut, y compris le moteur de simulation ngspice. Il n'y a **rien à installer** et la
simulation fonctionne **hors ligne**.

## Configuration requise

- Windows 10 ou Windows 11 ;
- aucune connexion Internet, aucun droit d'administrateur.

## Obtenir l'application

<Steps>

1. Télécharge **[`Psice.zip`](https://github.com/heigvd-2026-pythonge2-a/projet-gazouza/releases/latest/download/Psice.zip)**,
   la dernière version. Les versions précédentes et leurs nouveautés sont sur la page
   [Releases du dépôt GitHub](https://github.com/heigvd-2026-pythonge2-a/projet-gazouza/releases).

2. Fais un clic droit sur le fichier, puis **Extraire tout…**, et choisis un dossier (par exemple
   `Documents\Psice`).

3. Ouvre le dossier extrait et double-clique sur **`Psice.exe`**.

</Steps>

## Avertissement Windows SmartScreen

L'exécutable n'est pas signé numériquement. Au premier lancement, Windows peut afficher
« Windows a protégé votre ordinateur ».

1. Clique sur **Informations complémentaires**.
2. Clique sur **Exécuter quand même**.

Windows s'en souvient ensuite pour ce fichier.

## Psice ne démarre pas (version 0.1.0)

La version 0.1.0 ne démarre pas quand le zip a été téléchargé avec un navigateur : un message
d'erreur parle de `Python.Runtime`. Les versions suivantes corrigent ce problème. Avec la
0.1.0, débloque le zip avant de l'extraire :

1. Fais un clic droit sur `Psice.zip`, puis **Propriétés**.
2. Coche **Débloquer** en bas de l'onglet **Général**, puis clique sur **OK**.
3. Extrais le zip à nouveau.

## Désinstaller

Il suffit de supprimer le dossier de Psice. Tes schémas, enregistrés
où tu l'as choisi (fichiers `.psice.json`), ne sont pas touchés.
