Voici l'éditeur de Psice, directement dans ton navigateur : c'est la même interface que
l'application, reconstruite à chaque modification du code. Pose des composants, tire des fils,
règle les valeurs, annule, enregistre : tout fonctionne comme dans l'application.

<Aside type="note" title="La démo ne simule que les circuits d'exemple">
	La simulation a besoin de ngspice, qui tourne sur ton ordinateur avec
	l'[application Windows](/projet-gazouza/demarrer/installation/). La démo connaît à la place les
	**circuits d'exemple** ci-dessous et leurs vrais résultats ngspice : **Simuler** les redonne
	tant que tu ne changes ni les composants, ni leurs valeurs, ni les fils (les déplacer ne
	compte pas). Le courant y circule déjà sur le schéma (bouton **Arrêter l'animation** pour le
	figer).
</Aside>

<DemoFrame />

Rien n'est envoyé sur Internet : ton schéma reste dans ce navigateur. **Enregistrer** (<kbd>Ctrl+S</kbd>)
crée un fichier `.psice.json` sur ton ordinateur, que tu pourras rouvrir dans l'application.
